프로젝트 개요

본 프로젝트는 중간 프로젝트에서 개발한 일반 소프트웨어를 기반으로,

ML 관련 기능을 추가 및 확장하고 이를 실제 운영 가능한 형태로 관리하는 것을 목표로 한다.

특히 단순히 머신러닝 모델을 학습하는 것에 그치지 않고,

MLflow 기반의 실험 관리, 모델 관리, 재학습, 배포 및 운영까지 포함한

MLOps 파이프라인을 직접 설계하고 구축하는 것을 목표로 한다.



또한 본 과제는 기능 구현 자체보다,

“지속적인 개발 과정”, “모델 및 데이터 관리”, “자동화된 운영 파이프라인 구축”에 초점을 둔다.



* 프로젝트 내용

학생은 기존 중간 프로젝트를 기반해 아래를 수행한다.

1. 애플리케이션 개발

- 기존 DevOps 프로젝트에 ML 기능 추가

- 웹/CLI/AI/데이터 처리 프로그램 등 자유 주제

- 최소한 하나 이상의 ML 기반 기능 포함

2. Git 기반 개발

- GitHub 저장소 활용

- 지속적인 커밋을 통해 개발 과정 기록

- 코드 변경 및 모델 관련 변경 이력 관리

3. CI/CD 구축

- GitHub Actions를 활용하여 코드 push 시 자동 실행

- 테스트, 빌드, Docker 생성 등의 자동화 수행

- 필요 시 모델 학습 자동화 가능

4. Docker 기반 패키징

- 애플리케이션과 실행 환경을 하나의 컨테이너로 구성

- 어디서든 동일하게 실행 가능하도록 설정

5. MLflow 기반 모델 관리

- MLflow를 활용한 실험 기록 관리

- 학습 결과(metric, parameter, artifact) 저장

- 모델 버전 관리 및 비교 수행

6. 모델 재학습 및 반영

- 데이터 또는 설정 변경 후 재학습 수행

- 신규 모델을 서비스에 반영

- 모델 교체 또는 롤백 과정 관리

7. 배포 및 운영 확인

- Render/GCP 등 활용 가능

- 외부에서 접근 가능한 형태로 서비스 운영

- 로그 확인 및 운영 상태 관리



* 평가 기준

1. 전체 MLOps 파이프라인 완성도 (35)

- Git → CI/CD → Docker → MLflow → Deploy 흐름이 전체적으로 연결되어 동작하는가

- 코드 및 모델 변경 이후 전체 흐름이 자연스럽게 이어지는가

2. Git 이력 및 개발 과정 (10)

- 커밋이 지속적으로 이루어졌는가

- 개발 및 개선 과정이 Git 이력으로 드러나는가

3. 자동화 수준 (10)

- 코드 push 시 테스트/빌드 자동화가 수행되는가

- 모델 학습 또는 배포 과정 일부가 자동화되어 있는가

4. MLflow 활용 및 모델 관리 (15)

- MLflow를 활용하여 실험 및 모델 버전을 관리하는가

- metric, parameter, artifact 등을 기록하는가

- 모델 비교 및 관리 과정이 존재하는가

5. 애플리케이션 및 ML 기능 구성 (10)

- 최소 기능이 정상 동작하는가

- ML 기능이 실제 서비스와 연결되어 동작하는가

6. Docker 및 실행 환경 구성 (5)

- 컨테이너 기반 실행 환경을 구성하였는가

- 실행 환경 재현이 가능한가

7. 배포 및 운영 (5)

- 서비스 배포 및 실행 확인이 가능한가

- 운영 로그 또는 서비스 상태를 확인할 수 있는가

8. 추가 점수 (10)

- 모델 롤백 기능, 모델 자동 반영, 테스트 케이스 강화, 운영 로그 분석, 파이프라인 확장, 애플리케이션 복잡도 등을 추가 평가
