# Fix-02: 취약한 오픈소스 의존성 패치 (CWE-1104 / 다수 CVE)

## 1. 발생 원인 및 증상 (Red Run)
- `requirements.txt`에 명시된 `flask==2.2.5`, `jinja2==3.1.2`, `werkzeug==2.2.3` 패키지들이 알려진 취약점(CVE)을 다수 내포한 구버전으로 고정되어 있었습니다.
- CI 과정의 Gate 2 (pip-audit) 스캔 결과, 총 16건의 취약점(예: CVE-2024-56326 등)이 탐지되며 빌드가 실패했습니다.

## 2. 보안 취약점 영향
- 공격자가 이 구버전 패키지들의 알려진 취약점을 이용해 임의 코드 실행(RCE), 서버 자원 고갈(DoS) 등의 공격을 수행하여 서버 전체의 권한을 탈취하거나 마비시킬 수 있습니다. (공급망 및 의존성 취약점)

## 3. 조치 내역 (Fix)
- 기존 `requirements.txt`의 버전을 최신 안정화 버전으로 명시적으로 상향 업데이트했습니다.
- `flask>=3.1.0`
- `jinja2>=3.1.4`
- `werkzeug>=3.1.0`

## 4. 재검증 (Green Run)
- [ ] 패키지 버전을 올린 뒤 로컬 기능 테스트(`pytest`)를 100% 통과하여 앱 호환성에 문제가 없음을 확인했습니다.
- [ ] CI 파이프라인 재실행 결과 `pip-audit` 단계에서 0 vulnerabilities 로 탐지되지 않음을 확인했습니다. (추후 캡처 첨부)
